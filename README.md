# متجر بيجامات ولانجري — دليل البدء

هذا مشروع بداية باللغة العربية (RTL)، بألوان بيج ووردي، ويشمل عرض منتجات تجريبية وسلة ونموذج طلب بالدفع عند الاستلام.

## مهم قبل استخدامه تجاريًا
- أسماء المنتجات والأسعار والصور في النسخة الحالية أمثلة تجريبية. استبدليها بمنتجاتك وأسعارك الفعلية.
- من دون إعداد Supabase، الموقع لا يحفظ الطلبات على الإنترنت؛ سيعرض رسالة توضح أن قاعدة البيانات غير مفعلة.
- بعد تفعيل Supabase، يحفظ الطلبات في جدول `orders`. لا توجد لوحة إدارة مخصصة في هذه النسخة؛ يمكنك مراجعة الطلبات من لوحة Supabase بعد تسجيل الدخول.
- هذا قالب تعليمي أولي، وليس نظام تجارة إلكترونية مكتملًا. قبل الإعلان، اختبري الطلبات بنفسك، وأضيفي حماية من الرسائل المزعجة، والتحقق من الأسعار على الخادم، وسياسة خصوصية واضحة. لا تضعي مفاتيح سرية في `app.js`.

## 1) افتحي المشروع
1. نزّلي وفكّي ضغط الملف ZIP.
2. نزّلي Visual Studio Code: https://code.visualstudio.com/
3. افتحي VS Code ثم File > Open Folder واختاري مجلد المشروع.
4. افتحي `index.html` في المتصفح للتجربة. الأفضل تثبيت إضافة Live Server في VS Code ثم الضغط على Go Live.

## 2) عدّلي اسم المتجر والمنتجات
افتحي `app.js`:
- غيّري `name: "دارك"` إلى اسم البراند الذي تختارينه.
- عدّلي قائمة `products` لتغيير أسماء المنتجات والأسعار والوصف والتصنيف.
- حاليًا الصور أشكال زخرفية وليست صور المنتجات الحقيقية. لاستعمال صورك، ضعي الصور داخل مجلد `images` واستخدمي وسم `<img>` داخل بطاقة المنتج أو عدّلي `renderProducts()` في `app.js`.

## 3) فعّلي تسجيل الطلبات عبر Supabase
1. أنشئي حسابًا ومشروعًا في https://supabase.com/ (راجعي حدود الخطة المجانية الحالية).
2. من لوحة المشروع افتحي SQL Editor.
3. انسخي محتوى `supabase-schema.sql` والصقيه ثم اضغطي Run.
4. من إعدادات المشروع انسخي Project URL و anon/publishable key العام.
5. افتحي `app.js` واملئي:
   `supabaseUrl: "رابط مشروعك"`
   `supabaseAnonKey: "المفتاح العام"`
   لا تضعي `service_role` أو أي مفتاح سري في الواجهة.
6. جرّبي تسجيل طلب اختباري. من Table Editor افتحي جدول `orders` وتأكدي من ظهور الطلب.

### تنبيه أمني
المفتاح العام يُستخدم مع سياسات RLS، لكن السياسات الحالية تسمح بإرسال طلبات عامة وقد تتعرض للرسائل المزعجة. الأسعار والمجموع المرسلان من المتصفح ليسا مصدرًا موثوقًا. لا تعلني عن المتجر تجاريًا على نطاق واسع قبل إضافة تحقق خادمي من المنتجات والأسعار، ومكافحة إساءة الاستخدام، ومراجعة سياسة الخصوصية. لا توجد قراءة عامة للطلبات، فلا تضيفي سياسة قراءة عامة.

## 4) انشري الموقع مجانًا
خيار مبسط للموقع الثابت: Netlify أو GitHub Pages. راجعي الخطوات الحالية على المواقع الرسمية:
- Netlify: https://docs.netlify.com/
- GitHub Pages: https://pages.github.com/

لأن قاعدة البيانات مستضافة على Supabase، سيظل الموقع يرسل الطلبات إلى Supabase بعد النشر طالما الإعدادات صحيحة. اختبري ذلك من رابط النشر، وليس من جهازك فقط. الخطط المجانية لها حدود وقد تتغير.

## 5) ربطه بصفحة فيسبوك والإعلان
1. انشري رابط الموقع على صفحة البيزنس.
2. أنشئي إعلانًا من Meta Ads Manager واستخدمي رابط صفحة المنتجات أو الصفحة الرئيسية.
3. لا تختاري تتبع مشتريات كهدف محسّن قبل إعداد Meta Pixel/Conversions API واختباره.
4. قبل إنفاق المال، أرسلي طلبًا تجريبيًا وتحققي أنه يظهر في جدول `orders`، ووضحي للعميل مصاريف الشحن وسياسة الاستبدال والتواصل.
